# Atril Teleprónter 1.1.1 · Revisión de prueba

Corrige el aviso de error del selector de formatos al guardar una grabación en Linux Mint.

- Nombre propuesto sin extensión fija.
- Una sola extensión, de acuerdo con el formato elegido: WAV, FLAC o MP3.
- Confirmación antes de sustituir el destino definitivo.
- 52 pruebas automatizadas superadas, con exportación real en los tres formatos.

Para actualizar en Linux Mint, cierra Atril e instala el nuevo paquete desde su carpeta de descarga:

```bash
sudo apt install ./atril-teleprompter_1.1.1_all.deb
```

Esta revisión está pendiente de validación visual con el selector nativo. No se ha publicado como release en GitHub o GitLab.
