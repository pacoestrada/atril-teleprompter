# Atril Teleprónter 1.0.0

Primera versión pública del teleprónter para GNU/Linux de **Paco Estrada · Compilando Podcast**.

## Descargar e instalar

- **Linux Mint, Ubuntu y Debian:** descarga `atril-teleprompter_1.0.0_all.deb` y ábrelo con el instalador de paquetes, o ejecuta `sudo apt install ./atril-teleprompter_1.0.0_all.deb`.
- **Fedora:** descarga `atril-teleprompter-1.0.0-1.noarch.rpm` y ejecuta `sudo dnf install ./atril-teleprompter-1.0.0-1.noarch.rpm`.
- Tras instalarlo, busca **Atril Teleprónter** en el menú de aplicaciones.

Ambos paquetes contienen el mismo código y no incluyen bibliotecas Qt dentro del instalador. El gestor de paquetes instala Python y PyQt5 cuando sea necesario. Una vez instalado, Atril funciona sin conexión.

## Funciones

- Interfaz con identidad de Paco Estrada y Compilando Podcast.
- Lectura con velocidad, letra, ancho e interlineado ajustables.
- Teclado y ratón, con los atajos habituales visibles.
- Pantalla completa, cuenta atrás, guía de lectura y espejo horizontal.
- Editor integrado e importación de TXT, MD, DOCX y ODT.
- Guardado de sesión, recuperación del punto de lectura y del guion anterior.
- Temas de lectura Noche, Papel y Contraste.

## Validación y alcance

El proceso de publicación ejecuta las 23 pruebas automatizadas antes de construir los dos instaladores. Se ha revisado la presentación con Qt a tamaños de escritorio y portátil, y a escala 200 %. La instalación y lectura en escritorios reales de cada distribución todavía necesitan pruebas de uso. El RPM está preparado para Fedora; no se afirma compatibilidad con todas las distribuciones que usan RPM.

El avance es a velocidad fija: no sigue la voz ni graba audio o vídeo. La importación de Word y LibreOffice extrae texto sin reproducir su maquetación.

`SHA256SUMS.txt` permite comprobar la integridad de las descargas con `sha256sum -c SHA256SUMS.txt` desde la carpeta que contenga ambos instaladores.
